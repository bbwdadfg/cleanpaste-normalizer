# cleanpaste-normalizer

The existing repository README contains the shared behavior and privacy documentation for this package surface.

### CocoaPods
- **Ecosystem:** CocoaPods
- **Version:** `0.2.0`
- **Source:** `Sources/CleanPasteNormalizer.swift`
- **Local Test:** `ruby -c CleanPasteNormalizer.podspec`

This package provides `normalizePastedText`. The related web tool is https://cleanpasteai.com/. All processing runs locally without uploading input data.
